Connection

Troubleshooting / advanced

This page talks to BLE OBD-II adapters that expose a UART-style service (the common Nordic UART profile used by most generic ELM327 BLE clones, e.g. Vgate iCar Pro BLE, Veepeak, many unbranded dongles). If your adapter uses a different service, connection will fail with an error below — tell Claude the adapter model and the error text.
